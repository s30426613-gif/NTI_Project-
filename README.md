# Netflix Data Analysis Project

## Project Overview
This project analyzes the Netflix Movies and TV Shows dataset using Python and Google Colab. The goal is to explore the dataset, clean the data, and gain useful insights through data analysis and visualization.

## Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Dataset
- netflix_titles.csv

## Project Files
- `NTI_Project_Group2.ipynb` – Jupyter Notebook containing the analysis.
- `netflix_titles.csv` – Dataset used in the project.

## Objectives
- Clean the dataset.
- Explore Netflix content.
- Analyze movies and TV shows.
- Create visualizations to present insights.
